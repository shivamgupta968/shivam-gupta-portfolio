# Shivam Gupta — The Developer

A cinematic, responsive portfolio based on Shivam Gupta’s uploaded resume. The original portfolio design, animations, and section layout are retained; the content, profile photo, resume, projects, education, experience, and skills have been personalized.

## Run locally

1. Extract this ZIP.
2. Open the `Portfolio_series-main` folder in VS Code.
3. Open Terminal in that folder and run:

```powershell
npm.cmd install
npm.cmd run dev
```

4. Open the local URL printed by Vite (usually `http://localhost:5173/`).
